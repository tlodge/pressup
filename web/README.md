# PressUp web app

Mobile-first Next.js app for PressUp. See `../ROADMAP.md` for milestones and `../design/brand/design-system/README.md` for the brand book.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 at phone width (the layout is a 480px column, centred on wider screens).

## Deploy to Vercel

Import the repository in Vercel and set **Root Directory** to `web`. The framework preset (Next.js) and build command are detected automatically. No environment variables are needed until milestone 8.
