# Graphics

`pressup-figures-*.png`: the hand-drawn figure pattern, about thirty stick figures running, stretching, lifting and doing press-ups, drawn with the logo's round line. In press-yellow, black and white inks.

Use it for empty states, onboarding, the web footer, merch and packaging. Use it at one scale, as a block, and never mix it with photography in the same frame. Not for working screens.
