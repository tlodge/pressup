# Rings

The concentric hairline circles behind the poster photography. Drawn in `accent` at `stroke-hairline`, at `ring-faint` opacity.

Place inside a `position: relative` container, behind content. Centre them on the subject, such as an athlete's head, a timer or a headline, so they read as focus. Use two or three rings, never more than four, and never animate them continuously.

**Consumer provides:** a positioned parent; optional `count`, `size` (px diameter of the outer ring), `offset` (CSS translate).
