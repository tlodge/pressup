# WebHero

An example website page, not a component: the home page hero, proof strip and footer.

The website is the brand-moment register. Echo headline in `display-xl` press-yellow, black-and-white photography with rings, the tagline and figure pattern in the footer. The site is always dark, so this example ignores the light theme on purpose. Desktop gutter is `space-10`, the max content width is 1200px, and sections are `space-16` apart.
