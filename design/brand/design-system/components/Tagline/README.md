# Tagline

**Challenge • Motivate • Succeed**, set in the `label` style. The separators are small rings drawn in `accent`, the dot from the logo.

Use it once per surface: the web footer and hero, splash screen, share cards. Never inside working screens. Pass `words` for a campaign variant with the same three-beat rhythm, and `size` to scale it.

**Consumer provides:** optional `words` (array of three), optional `size` (CSS length).
