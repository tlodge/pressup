# EchoHeadline

The LOCKED IN device: a short headline repeated down the frame, each line fading through the `echo-1` to `echo-5` opacity tokens. Only the first line is read by screen readers.

The type is `press-yellow` in both themes; light only swaps the ground. On light it is decorative (about 1.2:1), so repeat any message it carries in readable text nearby.

For brand moments only: the web hero, a workout-complete screen, campaign art. Two words maximum, and a photo of an athlete can sit over the lower lines.

**Consumer provides:** `text`, `lines` (default 5), optional `size`.
