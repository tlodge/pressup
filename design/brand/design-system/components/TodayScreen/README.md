# TodayScreen

An example app screen, not a component: the Today tab, assembled from the system.

It shows the working-screen register. There's one display headline (`display-m`), the rest is Jost and Barlow Condensed, yellow appears only on the primary button, the active tab and the progress arc, and nothing is decorated. Phone gutter is `space-5`; sections are `space-6` apart.
