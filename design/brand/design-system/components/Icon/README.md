# Icon

A small line-icon set drawn to match the logo: a 24px grid, 2px stroke (`stroke-icon`), round caps and joins. Icons take `currentColor`.

Names: home, list, plus, minus, chart, user, play, pause, check, x, timer, chevron-right, arrow-up, arrow-down, flame, dumbbell.

**Consumer provides:** `name`, optional `size` (px, default 24), `title` (gives the icon an accessible name; leave it out when a visible label sits beside it).
