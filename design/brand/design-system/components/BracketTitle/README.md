# BracketTitle

The `[ DISCIPLINE ]` device from the posters: one value word in square brackets, in Anton, in `accent`. On light it is ink on an `accent-highlight` yellow band.

Use it for programme names, weekly themes and value statements. One per view. Never bracket a sentence; one or two words only.

**Consumer provides:** `children`, `size` (`s` 26px, `m` 40px, `l` 64px), optional `as` (heading tag, default `h2`).
