# Badge

A small status pill. Every tone carries an icon as well as a colour, so no state relies on colour alone.

- `pr`: personal record. `press-yellow` fill with a flame. Celebrate it, sparingly.
- `done`: completed set, session or week. `success` on `success-soft`, with a tick.
- `missed`: skipped session or failed set. `danger` on `danger-soft`, with a cross. Keep the copy neutral ("Missed", not "Failed").
- `neutral`: anything else (deload week, rest day).

**Consumer provides:** `tone`, `children` (one or two words).
